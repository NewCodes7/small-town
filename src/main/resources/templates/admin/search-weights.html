검색 동시 실행 상한

동시에 처리할 검색 요청 수의 상한입니다. 초과분은 대기하지 않고 즉시 429로 거절해 HikariCP 풀(5개) 앞에 큐가 쌓이는 것을 막습니다. 실측 처리량 정점은 VU10에서 14.3 RPS이고 VU15에서 꺾입니다. 변경은 재배포 없이 즉시 반영됩니다.

-
RAG 동시 실행 상한

동시에 처리할 RAG 스트림 수의 상한입니다. 초과분은 대기하지 않고 즉시 429로 거절합니다 (/api/rag/answer와 부하테스트 경로 모두). 실측으로 SLA(무부하 대비 120%)를 지킨 최고 동시성은 90입니다 — VU90에서 first_token p99가 1.09배(통과), VU105에서 1.27배(초과). p95는 VU120까지 1.07배로 평평하니 p95만 보고 판단하면 안 됩니다. 90은 Bedrock async 풀(120)보다 낮게 잡은 값이라 초과분이 풀 앞에서 조용히 대기하지 않고 반드시 429로 나갑니다. 힙은 166MB + N × 1.31MB(heap max 512MB)입니다. 변경은 재배포 없이 즉시 반영됩니다.

-
Clova 임베딩 서킷 브레이커 -

Clova가 죽거나 느려지면 호출 자체를 건너뛰고 BM25-only 검색으로 degrade 합니다. 4xx(키 만료·잘못된 요청)는 집계에서 제외하고, 408/429와 5xx·타임아웃·파싱 실패만 실패로 셉니다.
